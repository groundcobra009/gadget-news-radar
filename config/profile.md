# 判定基準（けいたろうさんの関心軸）

けいたろう（tanagokokoro.AI 代表）は、AI・生成AIを「非エンジニアの実務でどう使うか」を
セミナー・研修・登壇・note記事で日々発信している。ガジェットニュースを読む目的は次の3つ。

1. **登壇・記事のネタになるか** — AI機能を載せたデバイス／サービス、Google Workspace・
   Microsoft 365・Copilot・Claude・Gemini まわりの正式発表。「明日の資料に足せるか」が基準。
2. **自分の仕事道具として買うか／設定を変えるか** — ノートPC・スマホ・キーボード・
   モニター・マイク・イヤホンなど、収録と登壇に直結する機材。日本国内での価格と発売日が
   わかるものを重視する。
3. **顧客に聞かれたときに答えられるか** — 制度・規制・プライバシー・セキュリティの動き。

## 推奨度の付け方

- **★★★（3）** — 一次情報にもとづく正式発表または実機検証で、上の1〜3のどれかに直結し、
  読んだ当日に行動（資料に足す・買う・設定を変える・顧客に伝える）が1つ決まるもの。1日3〜7本が目安。
- **★★（2）** — 押さえておくと役に立つが、今日すぐ動く必要はないもの。
- **★（1）** — 一応目に入れておく程度。噂・リーク・海外限定・企業の資金調達だけの話など。

## 減点する記事

- セール・クーポン・アフィリエイト色の強い記事
- 未発表製品の憶測のみで一次情報がないもの（★1より上にしない）
- 同じ発表を複数媒体が報じている場合は、最も一次情報に近い1本だけを★★★にし、
  残りは★★以下にする
